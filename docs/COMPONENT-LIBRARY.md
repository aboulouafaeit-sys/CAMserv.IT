## 1. Component Registry & Overview

## 2. Core Operational Components

### 2.1 Top Command Bar (`#header-command-bar`)
* **Visual Style:** Glass Level 2 (`rgba(13, 20, 36, 0.85)` with `blur(24px)`).
* **Elements:**
  - **Cluster Status Pill:** Displays active term, leader node, and consensus state with glowing indicator (`🟢 Term 14 [Leader: nvr-01]`).
  - **Storage Lease Indicator:** Visualizes active writer lease countdown (`⚡ Lease: Valid (12s)`).
  - **Tenant Selector:** Dropdown displaying current administrative partition (`🏢 Enterprise Primary`).
  - **Judicial Audit Shield:** Direct link to tamper-evident audit logs (`🛡️ Audit Invariant: Verified`).
  - **Operator Profile & Theme Toggle:** Quick toggle between Dark and Daylight themes.

### 2.2 Camera Matrix Viewport Tile (`.camera-tile`)
* **Visual Style:** Glass Level 4 (`rgba(22, 34, 60, 0.65)` with `blur(12px)` and 1px gradient rim light).
* **Aspect Ratio:** Strict $16:9$ letterboxing (`aspect-ratio: 16 / 9`) with hardware-accelerated video canvas.
* **Overlays:**
  - **Top Bar:** Camera identifier, channel number, location tag, and recording status pulse (`🔴 REC`).
  - **Telemetry HUD:** Codec (`H.264`/`H.265`), resolution (`1080p60`), bitrate (`4.2 Mbps`), and packet loss indicator.
  - **Privacy Status Badge:** `🔒 PRIVACY MASK ACTIVE` indicating spatial face/plate redaction.
  - **Storage Fencing Badge:** `⚡ LEASED` or `⛔ FENCED WRITER`.
  - **Epistemic Badge:** `[REAL-HW]` or `[SIMULATED]`.

### 2.3 Forensic Evidence Card (`.evidence-card`)
* **Visual Style:** Glass Level 4 with Indigo accent rim lighting (`rgba(99, 102, 241, 0.25)`).
* **Metadata Fields:**
  - Primary Segment ID: Monospace string (`seg_cam-north_1794907200.mp4`).
  - Timestamp Range: ISO 8601 UTC start/end times.
  - Cryptographic SHA-256 Digest: Truncated monospace block with click-to-copy functionality.
  - Ed25519 Witness Seal: Validated signature badge (`✔ Merkle Root Verified`).
  - Dual-Control State: Single-officer vs Quorum-certified export badge.

### 2.4 Epistemic Truthfulness Badges (`.badge-epistemic`)
To adhere strictly to Rule 2.3, every data point displays its authoritative provenance:

| Badge Class | Label | Visual Styling | Meaning |
| :--- | :--- | :--- | :--- |
| `.badge-hw-verified` | `[HW-VERIFIED]` | Emerald outline + luminous green dot | Probed from physical silicon or camera hardware |
| `.badge-simulated` | `[SIMULATED]` | Amber outline + warning icon | Generated by test harness or synthetic video engine |
| `.badge-estimated` | `[ESTIMATED]` | Cyan outline + probabilistic icon | Output of deep learning detector (`is_prediction: true`) |
| `.badge-quarantined` | `[QUARANTINED]` | Crimson outline + lock icon | Unleased partial segment isolated from evidence store |
| `.badge-unavailable` | `[UNAVAILABLE]` | Slate gray muted outline | Missing physical device or unconfigured channel |

### 2.5 Timeline Playback Scrubber (`#timeline-scrubber`)
* **Visual Style:** Translucent dark track with fine minute and hour tick marks.
* **Recording Blocks:** Continuous recordings rendered in cyan (`--accent-cyan-glow`), motion events highlighted in amber, and tamper alarms in crimson.
* **Navigation Cursor:** High-visibility electric cyan needle with real-time timestamp tooltip.

### 2.6 Modal Dialog Sheet (`.modal-sheet`)
* **Visual Style:** Glass Level 6 (`rgba(16, 24, 44, 0.95)` with `blur(28px)` and cyan perimeter border).
* **Header:** Icon, title, close button (`×`), and keyboard shortcut reminder (`Esc to close`).
* **Content:** High-contrast form elements, monospace credential fields, and cryptographic hashes.
* **Footer:** Secondary cancel button, primary action trigger with prominent luminous state.

### 2.7 Interactive Action Buttons (`.btn`)
* `.btn-primary`: Luminous cyan button with dark obsidian text for high-contrast visibility.
* `.btn-secondary`: Translucent glass button with subtle white border and hover glow.
* `.btn-critical`: Deep crimson button with alarm glow for destructive actions (quarantine, purge).
* `.btn-judicial`: Indigo glass button with crest icon for courtroom export workflows.
